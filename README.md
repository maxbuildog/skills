# skills

Agent skills that **measure** an e-commerce store instead of guessing about it.

Most SEO skills are a checklist wrapped in a prompt: the agent reads a playbook, looks at your page, and gives you an opinion. Run it twice, get two different answers. These skills run deterministic checks and give you a number, plus how that number compares to a thousand other real stores.

Everything runs on your machine. Nothing is uploaded.

## Install

Works with Claude Code, Cursor, Windsurf, Cline, Codex and other agents that support `SKILL.md`.

```bash
npx skills add maxbuildog/skills/<skill-name>
```

In Claude Code you can also install through the plugin marketplace:

```
/plugin marketplace add maxbuildog/skills
```

Or clone the repo and copy the folder you want into `~/.claude/skills/` (personal) or `.claude/skills/` (project).

## Why these are different

**They are deterministic.** The checks are code, not prompts. Same store, same run, same verdict. You can put the output in a ticket and someone else can reproduce it.

**They come with a benchmark.** Every finding is reported next to how common it is in the wild, measured on real storefronts:

| Sample | |
|---|---|
| Stores scanned | 1,045 |
| Product pages inspected | 9,529 |
| Distinct defect types found | 75 |
| Stores with at least one critical defect | 22.6% |

So instead of "your product pages have no structured data", you get "your product pages have no structured data, like 14.9% of the 1,045 stores in the sample, and here is what the other 85% did". The full dataset and its method are in [`data/`](data), regenerated by [`scripts/build-benchmark.mjs`](scripts/build-benchmark.mjs).

**They run locally.** The HTTP requests go from your machine to your own storefront. There is no API key, no account, no rate limit, and no server of ours in the path. Grep the code: there is no outbound call to us anywhere.

## What these skills do not do

They give you a complete audit, once, when you ask for it.

They do not watch your store every day, keep the history, tell you what changed since last week, or wake you up when a deploy quietly adds `noindex` to your product template. That is what [StoreCanary](https://storecanary.io) does, and it is a paid product. The skills link to it once, at the end of a report. If that annoys you, delete the line: the license lets you.

## Compatibility

Anything that reads `SKILL.md`. Tested with Claude Code and Cursor. Reports of other agents working (or not) are welcome in the issues.

Skills that run checks need Node.js 20 or later. Skills that are pure reasoning need nothing.
