# Code of conduct

Short version: be decent, and argue about the work rather than the person.

## Expected

- Assume the other person is trying to help.
- Criticise code, findings and reasoning. Not people.
- When you are wrong, say so and move on. It costs nothing here.

## Not accepted

- Harassment, insults, or personal attacks, in issues, pull requests or commit messages.
- Publishing someone's private information.
- Using an issue thread to advertise a product. That includes mine.

## Enforcement

Report anything that crosses the line to **conduct@storecanary.io**. Reports stay between you and me.

Responses range from a request to edit a comment, to removing the content, to blocking the account, depending on what happened. I will explain the reasoning where it is possible to do so without exposing whoever reported it.

This is a small repo run by one person. Do not expect a committee, do expect a reply.
